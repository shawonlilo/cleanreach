Paste or drop your list

CSV with email,phone,consent columns, plain email lists, or messy text — CleanReach extracts, dedupes, verifies and classifies it on this device. Your list is never uploaded anywhere. Only clean lists you own or are authorized to use.

Disposable / temp addresses are removed from the clean export by default. Free providers (Gmail etc.) are marked risky, never fake-“valid”. Unknown ≠ invalid.

Domain health

      
A, MX, SPF and DMARC for any domain — the same checks CleanReach uses when classifying your list's domains.

      

      

      

    

  


  
  

    

      
Engines

      
Native Rust engine (built-in, default) — syntax, disposable detection, MX/SPF/DMARC, lanes, phones. Fully offline, deterministic, no AI calls with your lists, ever.

      
Optional sidecar engines — TrueMail Go and AfterShip email-verifier can run as your own local HTTP services and be consulted as a second opinion. See ENGINES.md in the repository. CleanReach ships with no credentials: any API key a sidecar needs is yours (BYOK), entered on your own service, never in this app.

      
      
      
🔒 SMTP probing is off by default and only available in the CLI (--smtp-probe) for lists you own — it is intrusive by nature, so it is never a silent default.
