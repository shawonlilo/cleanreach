# CleanReach — design direction

**One generator direction (taste-skill / hallmark layering):** a calm,
deep-ink workspace where a single mint action does the work and amber is
reserved for the two things that deserve attention — risk and consent.
No gradients. No glass. No purple/blue AI glow. No stock imagery. If a
colour appears, it means something:

- **Mint `#3ED598`** = clean, verified-enough, the primary action.
- **Amber `#F2B33D`** = risky / unknown / the consented-phone bridge.
- **Red `#F26D6D`** = disposable or invalid — out of the clean export.
- **Slate blue `#7FB4C7`** = role accounts (information, not danger).

**Identity:** deep ink + mint + amber. Deliberately distinct from
Network Diagnostics (emerald/gold on blue-black): CleanReach is
green-black ink, a brighter clinical mint, and a warmer amber. Logo: a
mint droplet with a check cut through it and one amber dot — the clean
contact you actually reach.

**Screens (one job each):** Dashboard (paste → clean) → Lanes & Exports
(filter chips, one-click lane downloads) → File Toolkit (split/merge) →
Phone Validator → Domain Health → Engines & Settings (BYOK honesty).

**Rules:**
- The hero button says the outcome: **CLEAN MY LIST**. Never "Submit".
- Every export is reachable in ≤3 clicks: paste → clean → download lane.
- Lanes are words with reasons, never codes. Every row shows *why*.
- Honesty is UI copy, not fine print: "Unknown ≠ invalid",
  "risky, not fake-valid", "line type: unknown" appear where the data is.
- Emoji are used sparingly as wayfinding in headings/buttons (owner
  preference), never as data. Data is text, colour and counts.
- Dark theme only in v0.1 — a tool people run next to terminals and
  spreadsheets. System fonts only; works fully offline.
